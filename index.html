常见问题

为什么这里没有十几块的 ChatGPT Plus，也没有便宜的中转 API？

这类低价多来自成品号、合租共享、接码注册的账号，或号池、逆向接口拼的中转，容易封号。这里只列官方订阅、官方地区价、官方 API 和云厂商渠道。

买了订阅，能拿去抵扣 API 调用费吗？

通常不能。ChatGPT、Claude、Gemini 的订阅只覆盖各自 App 内的用量，API 要在对应的开发者平台单独充值按量计费。例外只有 Claude Max / Ultra 每月附送的 $100 / $200 API 额度。

同一个模型，为什么每家的 Token Plan 价格差这么多？

国内 Token Plan 是积分制，各家积分的消耗算法不同，标价不能直接换算；海外订阅是包月制，比月费和用量上限。这里按模型分区，口径、续费价和额度都写在卡片里。

在云厂商那里买 API，和直购有什么区别？

主流模型在 AWS Bedrock、Azure OpenAI、Vertex AI 上的按量价和直购基本一样，差别在账单走云账号、数据处理区域可选、批量任务半价、企业协议折扣。

价格表里的「工具」行是什么？和官方订阅是一回事吗？

不是一回事。「工具」行是 Cursor、Copilot 这类 Harness：在工具里也能调用这个模型，用量按工具自己的额度算（credits、次数或美元用量池），和官方订阅分开计——工具里的额度用完，不影响你的官方订阅，反过来也一样。表里把工具的价格和官方额度一起列出来，方便和订阅、API 对照。

这里的价格是实时的吗？
